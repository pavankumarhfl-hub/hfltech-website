HFL TECH / RESEARCH

Research that stays connected to engineering.

HFL Tech uses research as a way to investigate intelligent software systems, agent architectures, evaluation and responsible automation without presenting experiments as finished products.

AGENT SYSTEMS

Context & planning

Explore how goals, context, planning, tools and state can be organised into inspectable agent workflows.

EVALUATION

Reliable execution

Investigate task completion, validation, authorization and reproducible evaluation rather than relying only on generated output.

AUTOMATION

Tool-driven workflows

Study how models can interact with tools and workflows while preserving explicit permissions and human control.

RESPONSIBLE AI

Control boundaries

Research least privilege, human approval, auditability and clear boundaries between reasoning and action.
