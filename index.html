Featured Project

AgentMesh

AI agent technology project founded by Pavan Kumar BN within HFL Tech, exploring orchestration, tools, memory, intelligent task execution, automation and developer workflows.

Agent lifecycle

Goal intake → Context → Planning → Tool selection → Execution → Observation → Evaluation → Completion or human approval.

Security

Least privilege, authorization, credential isolation, validation, auditability and human control.

Architecture

Application → Agent runtime → Model → Tools/APIs → State/Memory → Evaluation/Observability.
