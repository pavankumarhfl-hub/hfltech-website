## AgentMesh

AgentMesh is HFL Tech's flagship super intelligence product. It is designed to move beyond a simple chat interface by working around the complete task: understanding the objective, using relevant context, coordinating authorised tools, executing work, evaluating outcomes and keeping people in control of important actions.
