Methodology

What a credible benchmark must contain.

A future leaderboard will use the same task set, prompts, evaluation criteria and scoring rules for every system that can be tested comparably.

01
Task set

Identical, versioned tasks covering reasoning, coding, tool use and agent execution.

02
Scoring

Predefined correctness, completion, latency and control metrics.

03
Reproducibility

Record model/version, date, prompts, configuration and test outputs.

04
Percentile

Calculate percentile only from the measured comparison set; never estimate it from marketing claims.

Current evidence: AgentMesh has a runnable browser-side reference implementation and self-tests. The current 100% figure refers only to the six defined reference-runtime checks. A cross-model percentile will be published only after comparable tests are actually run.
