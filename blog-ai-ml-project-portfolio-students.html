AI ENGINEERING · STUDENT GUIDE

AI/ML projects that make a student portfolio credible

A strong AI project is not just a model that runs. It is a reproducible experiment with a clear question, a fair baseline, measurable evaluation and honest limitations.

Start with a question that can be tested

Choose a bounded problem such as classifying a public dataset, forecasting a clearly defined signal, searching a small document collection or comparing retrieval strategies. State what success means before choosing a model.

Document your data

Record the source, licence, collection date where relevant, preprocessing and any exclusions. Check for leakage between training and test sets. Avoid datasets containing private or sensitive information unless you have a legitimate basis and suitable safeguards.

Compare against a baseline

A simple baseline makes results interpretable. Compare it with your proposed method using metrics appropriate to the task. For classification, consider precision, recall and class balance rather than accuracy alone. For retrieval, define relevance and evaluate the ranking. Explain why a metric fits the problem.

Make the experiment reproducible

Include environment setup, dependency versions, configuration, random seeds where useful, evaluation scripts and a small example. Keep API keys and private data out of Git. A reviewer should be able to understand what the code does without guessing.

Explain failure cases and limits

Show where the model performs poorly, what assumptions it makes, and what would need to change before deployment. For generative AI, test hallucinations, prompt injection, data exposure and unsupported answers. Do not describe a prototype as production-ready without evidence.

Present your contribution clearly

Use a concise README with the problem, architecture, results, limitations and next steps. Include a short demo or screenshots when useful. If you used AI coding tools, explain how you reviewed, tested and understood the output.

Next steps

Choose a project you can finish and defend in a technical conversation. Then review the internship portfolio guide and the HFL Tech online internship information. Specific project assignments and selection are confirmed individually.
