AgentMesh

AI agents that can plan, use tools and execute workflows.

AgentMesh is an AI technology project founded by Pavan Kumar BN within HFL Tech. It explores agent orchestration, intelligent task execution, automation and developer workflows.

Read technical documentation

Agent lifecycle

1. Goal

Understand the user's intended outcome and constraints.

2. Context

Collect relevant state, information and available capabilities.

3. Planning

Break the objective into executable steps.

4. Tools

Select authorized tools and services for each step.

5. Execution

Perform actions and observe their results.

6. Evaluation

Validate the result and request human approval when required.

Security by design

The project direction emphasizes least privilege, authorization, credential isolation, validation, auditability and human control.
